# Учётная система отеля «Точка останова»

Учебный проект на платформе 1С:Предприятие 8.3. Доработка каркасной конфигурации с подсистемами БСП: от бронирования номера до расчёта зарплаты сотрудников.

## Что реализовано

- Документ «Бронирование»: клиент, гости, даты, номер и дополнительные услуги.
- Цены номеров и услуг хранятся в периодическом регистре сведений.
- Контроль занятости: бронь записывается в регистр по дням, на занятые даты документ не проводится.
- Печатная форма счёта на оплату через подсистему «Печать» БСП.
- Документ «Оплата» и регистр накопления «ВзаиморасчетыСКлиентами»: оплата частями, отчёт по задолженности.
- Расчёт зарплаты: оклад по графику, премия, отпуск и больничный.
- Отражение зарплаты в бухучёте: проводки Дт 26 – Кт 70.
- Роли для менеджеров и бухгалтеров через группы и профили доступа БСП.

## Структура

- `src/` выгрузка конфигурации в файлы

## Как запустить

1. Скачайте файл `.dt` из раздела Releases.
2. Создайте пустую информационную базу.
3. В Конфигураторе выберите Администрирование → Загрузить информационную базу и укажите файл.
